# 코드 스타일 규칙

## 중괄호 · 들여쓰기
- K&R 스타일 (여는 중괄호 같은 줄), 단일 라인도 중괄호 생략 금지
- 들여쓰기: 탭(Tab) 사용, 한 줄 최대 120자

```csharp
// ✅
if (isAlive) {
    TakeDamage();
}
// ❌ 중괄호 생략 / Allman 스타일 금지
```

## 빈 줄
- 메서드 사이: 1줄 / `#region` 시작 직후·직전: 1줄 / 파일 끝: 1줄

## using 정렬 순서
System → UnityEngine → 서드파티 → 프로젝트 내부 (그룹 사이 빈 줄 1줄)

## var 사용 기준
- ✅ 허용: 우변에서 타입이 명확히 보일 때, foreach 변수
- ❌ 금지: 우변만 봐서 타입 불명확할 때

## ⛔ 금지 패턴 목록
- 중괄호 생략 → 금지
- Allman 스타일 중괄호 → 금지
- 타입 불명확한 곳에 var 사용 → 금지
