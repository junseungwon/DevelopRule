## 테스트 케이스 작성 원칙

### Given-When-Then 형식 필수

```markdown
#### TC-{번호}: {테스트 이름}
- Given: {초기 상태·전제 조건}
- When: {수행할 액션}
- Then: {기대 결과}
- 심각도: Critical / High / Medium / Low
```

### 엣지케이스 4축 (최소 각 1개 이상)

| 축 | 설명 | 예시 |
|----|------|------|
| 비정상 입력 | 범위 외 값, null, 빈 값 | 체력 -9999, null 타겟 |
| 동시성 | 동시 입력, 중첩 트리거 | 두 능력 동시 발동 |
| 리소스 실패 | 씬 전환 중, 오브젝트 파괴 후 | 파괴된 젤리에 능력 발동 |
| 상태 경계 | 최솟값, 최댓값, 상태 전환 직전 | 체력 0인 상태에서 흡수 |

## 버그 리포트 형식

```markdown
### BUG-{번호}: {버그 요약}
- 심각도: Critical / High / Medium / Low
- 재현 경로: {단계별 절차}
- 기대 결과: {정상 동작}
- 실제 결과: {현재 버그 동작}
- 재현 빈도: 항상 / 가끔 / 드물게
- 환경: {Unity 버전, 플랫폼, 기타}
```
