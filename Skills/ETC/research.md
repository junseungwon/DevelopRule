| 속성 | 값 |
|------|-----|
| 스킬명 | research |

## 조사 원칙

### 출처 신뢰도 계층

```
공식 문서
  > 공식 포럼·GitHub 공식 레포
  > GitHub Issue/PR (검증된 것)
  > 검증된 기술 블로그
  > 커뮤니티 Q&A
```

### 필수 확인 사항

- 최신 버전 기준 정보 확인 (버전 불일치 주의)
- 추정·의견과 확인된 사실을 분리 표기
- 라이선스·유지보수 활성도 확인 (외부 의존 도입 시)

## Unity 전용 조사 항목 (unity-researcher)

Unity 관련 조사 시 추가로 확인:

- Unity 최소 지원 버전 (Minimum Unity Version)
- UPM 패키지 여부 (Package Manager 설치 가능 여부)
- IL2CPP 호환성 (모바일 빌드 대상 시)
- Unity 규칙 저촉 여부 (특히 UNITY-027 Reflection, UNITY-014 Memory)
