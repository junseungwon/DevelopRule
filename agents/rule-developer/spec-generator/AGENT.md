# Spec Generator Agent (명세 생성자 에이전트)

## 📋 에이전트 정의

| 속성 | 값 |
|------|-----|
| **에이전트명** | spec-generator |
| **역할** | 규칙 설계 기반 개발자 에이전트 명세 생성 |
| **타입** | 전문 명세 에이전트 |
| **입력** | rule-design-spec.md |
| **출력** | developer-agent-spec.md |

## 🎯 책임

### 1. 규칙 설계 검토
- designer가 생성한 rule-design-spec.md 분석
- 규칙 정의, 조치, 자동화 가능 여부 파악

### 2. 개발자 에이전트 요구사항 정의
- 규칙 검증 로직
- 필요 도구/스킬
- 워크플로우
- 입출력 명세

### 3. 에이전트 명세서 작성
- 에이전트 정의
- 책임 및 기능
- 필요 스킬 목록
- 상세 워크플로우
- 스킬 명세 작성
