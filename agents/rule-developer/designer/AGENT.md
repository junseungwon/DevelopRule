# Designer Agent (설계자 에이전트)

## 📋 에이전트 정의

| 속성 | 값 |
|------|-----|
| **에이전트명** | designer |
| **역할** | 코드 분석 결과 기반 규칙 설계 |
| **타입** | 전문 설계 에이전트 |
| **입력** | code-analysis-report.md |
| **출력** | rule-design-spec.md |
| **스킬** | SKILL.md 참고 |

---

## 🎯 책임

### 1. 분석 보고서 검토
- analyzer가 생성한 code-analysis-report.md 분석
- 주요 코드 패턴 및 스타일 규칙 이해

### 2. 규칙 설계
각 발견된 패턴/스타일에 대해:
- 규칙명 정의
- 적용 조건 설정
- 조치(Action) 결정
- 심각도 결정

### 3. 규칙 정의서 작성
- 규칙 목록
- 각 규칙의 상세 명세
- 위반/준수 예시
- 자동화 가능 여부
