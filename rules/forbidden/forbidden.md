# 금지사항 규칙

## 코드 및 파일 조작

- 파일을 Read로 먼저 읽지 않고 수정하는 것을 금지한다.
- 요청 범위를 벗어난 코드 변경, 리팩토링, 기능 추가를 금지한다.
- 요청하지 않은 주석, docstring, 타입 어노테이션 추가를 금지한다.
- 사용하지 않는 코드에 `_` 접두사, re-export, `// removed` 주석 등 하위 호환 핵을 추가하는 것을 금지한다.
- 단발성 작업을 위한 helper, utility, 추상화 레이어를 만드는 것을 금지한다.

---

## Git 및 원격 작업

- 사용자 명시적 요청 없이 `git push`, PR 생성, 이슈 코멘트 등 외부에 영향을 주는 작업을 금지한다.
- `--no-verify`, `--force`, `reset --hard` 등 파괴적 git 명령을 무단으로 실행하는 것을 금지한다.
- 기존 커밋을 `--amend`로 수정하는 것을 금지한다 (명시적 요청 제외).

---

## 보안

- SQL 인젝션, XSS, 커맨드 인젝션 등 OWASP Top 10 취약점을 유발하는 코드를 작성하는 것을 금지한다.
- 사용자가 제공하지 않은 URL을 추측하여 생성하거나 호출하는 것을 금지한다.
- 인증 정보, `.env`, 시크릿 파일을 커밋에 포함하는 것을 금지한다.

---

## 응답 스타일

- 이모지는 사용자가 명시적으로 요청한 경우에만 허용한다.
- 작업 완료 후 수행 내용을 장황하게 요약하는 것을 금지한다.
- 불필요한 시간 예측, 소요 시간 언급을 금지한다.

---

## 규칙 관리

- `~/.claude/CLAUDE.md`에 직접 규칙 내용을 작성하는 것을 금지한다.
- 규칙, 스킬, 에이전트 외의 내용을 `C:\DevelopRule\rules` 외부에 작성하는 것을 금지한다.
