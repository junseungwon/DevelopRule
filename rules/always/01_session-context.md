# 세션 및 컨텍스트 관리

1. **`/clear` 생활화:** 새로운 작업 시작 시 반드시 세션을 초기화하여 누적된 토큰 비용을 아낍니다.
2. **`/compact` 정기적 사용:** 디버깅이 길어질 경우 이전 대화를 요약 압축하여 컨텍스트 창을 비웁니다.
3. **작업 단위 세분화:** 한 번에 여러 버그를 고치지 말고, 하나의 세션당 하나의 기능만 지시합니다.
4. **불필요한 히스토리 삭제:** 잘못된 방향으로 흘러간 대화는 과감히 지우거나 세션을 재시작합니다.
5. **대용량 파일 Read 금지:** 300줄 이상의 파일 전체 읽기 대신 `grep`이나 부분 `view` 검색을 지시합니다.
6. **`.claudeignore` 활용:** `Library/`, `Logs/`, `*.asset`, `*.png` 등 코딩과 무관한 파일을 완벽히 차단합니다.
7. **세션 분리:** UI 작업 세션과 물리(Physics) 작업 세션을 별도로 분리하여 컨텍스트 혼침을 막습니다.
8. **시스템 프롬프트 경량화:** 너무 많은 전역 규칙은 매번 토큰을 소모하므로 최소한으로 유지합니다.
9. **컨텍스트 미아 방지:** AI가 엉뚱한 코드를 수정하려 하면 즉각 중단(Interrupt) 시킵니다.
