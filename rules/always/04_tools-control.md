# 명령어 및 외부 도구 제어

28. **위험한 Bash 플래그 제한:** `-y` 나 강제 삭제(`rm -rf`) 명령어 사용을 억제합니다.
29. **명확한 Bash Description:** 도구 설명은 명확한 한국어나 영어로 통일해 툴 인식률을 높입니다.
30. **웹 검색(MCP) 차단:** 외부 API 문서 검색이 필요 없는 단순 로직 작업은 검색 도구를 비활성화합니다.
31. **Git Diff 적극 활용:** 파일 수정 후 `git diff`를 통해 AI가 스스로 변경 사항을 검증하게 합니다.
32. **파일 경로 명확화:** 새 파일을 생성할 때 루트가 아닌 정확한 타겟 서브 디렉토리를 지정합니다.
33. **터미널 출력 제한:** 긴 로그 확인 시 `tail -n 50`이나 `grep`을 사용하도록 유도하여 토큰을 방어합니다.
34. **사전 환경 파악 지시:** 코딩 전 `ls`나 `cat`으로 디렉토리 상태를 먼저 탐색하도록 합니다.
35. **빌드 자동화 연동:** 수정 완료 후 백그라운드에서 자동 빌드/테스트 스크립트를 실행하게 세팅합니다.
36. **린터(Linter) 도구 활용:** 코드 작성 후 프로젝트에 내장된 포매터/린터를 실행하게 룰을 추가합니다.
