# 모델 스위칭 및 비용 효율화

37. **Opus 모델의 제한적 사용:** 프로젝트 전체 구조 설계나 복잡한 아키텍처 기획 시에만 사용합니다.
38. **Sonnet 모델 적극 활용:** 단순 버그 수정, 오타 수정, 주석 추가는 빠르고 저렴한 Sonnet을 씁니다.
39. **OpusPlan 기법 적용:** Opus로 전체 작업 계획만 짜고, 실제 코딩은 Sonnet에게 넘겨 비용을 절약합니다.
40. **Extended Thinking 제어:** 단순 타이핑 작업에 AI가 불필요하게 깊게 추론하지 않도록 차단합니다.
41. **잦은 Git Commit:** 토큰이 낭비된 후 롤백하지 않도록, 작은 작업(원스텝)마다 커밋해 둡니다.
42. **불필요한 인삿말 생략:** "안녕", "부탁해", "고마워" 등 불필요한 프롬프트 텍스트를 줄입니다.
43. **반복 지시사항 문서화:** 매번 타이핑하는 지시사항은 `CLAUDE.md`로 빼내어 토큰을 절약합니다.
44. **에이전트 모드 주의:** AI가 자율적으로 판단하는 에이전트 모드에서는 토큰 한도를 타이트하게 설정합니다.
45. **응답 길이 제한:** 너무 긴 설명이 예상되면 "코드 리뷰 결과의 핵심만 3줄로 요약해"라고 제한합니다.
