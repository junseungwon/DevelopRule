# 파일 분산 및 CLAUDE.md 최적화

19. **가벼운 Root 규칙:** 프로젝트 최상단 `CLAUDE.md`는 목차(Index)와 핵심 규칙만 남깁니다.
20. **메모리 분산 배치:** 하위 도메인(모듈) 폴더별로 전용 `CLAUDE.md`를 만들어 규칙을 분산시킵니다.
21. **@ 참조 자제:** `@파일명` 호출은 컨텍스트를 즉시 차지하므로, 필요시 경로(Path)만 텍스트로 알려줍니다.
22. **팀 컨벤션 문서화:** 명명 규칙, 아키텍처 패턴 등을 명문화하여 AI가 일관성을 유지하게 합니다.
23. **디렉토리 구조도 첨부:** 규칙 파일 내에 프로젝트의 간략한 트리(Tree) 구조를 주석으로 남깁니다.
24. **라이브러리 버전 명시:** 사용 중인 Unity, C#, 외부 패키지 버전을 기재하여 구버전 API 사용을 막습니다.
25. **지역/전역 규칙 분리:** 특정 폴더에서만 쓰이는 규칙이 전역으로 새어나가지 않게 엄격히 분리합니다.
26. **필수 주석 룰 정의:** AI가 코드를 짤 때 XML 주석이나 인라인 주석을 달도록 규칙에 강제합니다.
27. **단위 테스트 룰 지정:** 핵심 코드 수정 시 관련된 단위 테스트 코드도 함께 수정하도록 명시합니다.
