# Unity 주석 규칙

## 핵심 규칙 (항상 적용)
- [SerializeField] 변수 → [Tooltip] 필수
- public 메서드·클래스·프로퍼티·변수 → /// <summary> 필수
- 주석은 Why 위주, What 설명 금지
- // 뒤 스페이스 한 칸 필수
- 장식용 주석 금지 (//-----, //##### 등)
- 메서드 내부 #region 사용 금지
